# Teamily

An iOS-style AI agent team workspace with a liquid glass interface.

- Single file app: `index.html` (no build step, no server)
- Screens: Chats, Agents, Agent Teams, Automations, Discover, Memory, Artifacts
- Liquid glass UI: layered translucent surfaces, backdrop blur, specular highlights
- State persists in `localStorage`

## Run locally

Open `index.html` in any modern browser.

## Deploy

GitHub Pages is enabled for this repository. Every push to `main` republishes the live preview.
